## Implementation

Seven guarded patch boundaries:

| Address | Replacement |
|---|---|
|0074B7A0|Full snapshot capture, or cache capture during a pending restore|
|0074BA20|Restore traffic/reference records and extra state|
|0074BB80|Import full payload into owner-specific cache and preserve native phase handling|
|0074C57D|Save traffic array from separate storage|
|0074C59F|Save reference pairs from separate storage|
|0074DF09|Load traffic into separate storage with a bounded native mirror|
|0074DF4A|Load reference pairs into separate storage with a bounded native mirror|

The original612-byte caller views and624-byte embedded object remain intact.
Complete arrays live in a2660-byte private payload:150 traffic IDs,256 retained
ID/reference-count pairs and extra state. The recorded traffic/reference counts
and variable-length record format are unchanged. This avoids moving all later
members in the large replay manager. Full consumers are adapted at both sides;
the inline mirrors hold only their original50 IDs/pairs.

The retained collector matches all three sources in native`005A69B0`: positive
references in`+998`, pending nodes with zero`+C` state in`+D94`, and the special
model at`+D9C` when spool state`+DAC` is2. It preserves iteration order and uses
native`005A6B00` for reference counts. Restore preserves the original ordering:
traffic request, current reference release, recorded reference reacquisition,
extra state, native phase2. Native phase1/2 ticking remains unchanged.

Temps are scoped to synchronous save/load/restore operations and recycled
across stack addresses/threads. Cached payloads persist per object address;
an import replaces the cache, while state0 capture always reads the live lists.
There is no fixed owner-count registry. Bounds, pointer/prefix consistency and
cache/temp guards are checked. Startup verifies all original producer/import/
restore bytes and the four call operands before an all-seven patch commit;
failed commits have exact rollback checks. Fatal refusal logs the reason and
exit code`0x29F4`; no arbitrary ID substitution or loading-gate bypass is used.

This extends snapshot reference storage, not the actual game's retained pool.
All inherited capacities remain150 requests/160 graphics/ED+EF, parked150,
audio model192/slots2048/default64MiB, pending512, cleanup262144 and callback512.
